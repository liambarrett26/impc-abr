## The count X

**Authoritative source:** the IMPC's own statistical output, `/Volumes/IMPC/stat_processed_data.csv` (Release 22.1; 44,862 tests across 6,749 genes × 8 ABR-procedure parameters).

**The control threshold is applied per sex, not on the combined total.** The IMPC runs the Reference Range Plus framework on the sexes separately, so it requires ≥60 controls *of a given sex*, not ≥60 controls in total. Empirically, among the 36,591 processed ABR tests, every one has ≥60 controls in at least one sex (minimum female 57, minimum male 83); **no** processed test has both sexes below 60. Conversely the unprocessed tests are dominated by lines with both sexes below 60 — e.g. the recurring WTSI ABR_001 pattern of 54 female + 44 male = 98 controls, which passes a naïve "total ≥60" test but fails the real per-sex rule.

A gene knockout is counted as "too few controls" when, for an ABR threshold parameter (6/12/18/24/30 kHz or click), the test was **not processed** (`statistical_method` blank) and **both** the female and male matched-control counts were **< 60**. The mutant requirement is essentially non-binding: the IMPC processed tests with as few as 2 mutants (e.g. *Tmco2*, 0 F + 2 M, processed against ample controls), so controls — not mutants — are the limiting factor in these cases.

## Where the control shortage comes from

The IMPC does **not** compare a mutant line against its centre's whole control pool. Controls are matched within a narrow silo defined by centre + genetic background + zygosity baseline + **metadata group** (the ABR stimulus configuration and equipment) + temporal proximity, and the per-sex ≥60 rule is then applied to that silo. The reported `*_control_count` is the silo size, not the centre pool. This is confirmed against IMPC documentation: controls are grouped by background strain, allele/colony, zygosity, pipeline, procedure, parameter, **metadata group**, organisation and sex, with same-facility matching ([Mutants and controls](https://www.mousephenotype.org/help/data-analysis/mutants-and-controls/), [Statistical analysis](https://www.mousephenotype.org/help/data-analysis/statistical-analysis/)). Reconstructing each silo from the raw data reproduces the IMPC's exact per-sex counts.

### ABR_001 (all temporal)

At WTSI the metadata is uniform, so the only variable is *when* a line was run. Early lines (2012–13) drew a small contemporaneous control set — the recurring 54 F + 44 M = 98 — while later lines (2014–16) drew the full accumulated baseline (397 F + 409 M = 806). The 98-control lines are exactly the unprocessed set; the 806 lines are exactly the processed set. Same equipment, software, pipeline, recording environment and C57BL/6N background throughout — only the date differs. (The even smaller 11/43-control WTSI lines are the separate B6Brd;B6N-Tyr<c-Brd> albino sub-line — a genuine background difference.)

### ABR_002 (three mechanisms)

The 126 ABR_002 control-limited groups (115 genes) fall into three interpretable classes, each reproduced exactly from the raw data. These are the values in the `shortage_mechanism` column of `abr_002_control_shortage_evidence.csv`.

| `shortage_mechanism` | Groups | Genes | Centres | What it means |
|---|---|---|---|---|
| **Stimulus/equipment config** | 65 | 63 | Harwell 53, KMPC 6, HMGU 4, CCP-IMG 1, MARC 1 | The line was run under a stimulus/equipment configuration shared by <60 controls per sex |
| **Time-based control-matching** | 50 | 41 | TCP 50 | Same background and procedure, but only an early control cohort was used |
| **Genetic Background control-matching** | 11 | 11 | RBRC 8, JAX 2, HMGU 1 | The mutant's genetic background has no / too few matched controls |

**Stimulus/equipment config (65).** Matching controls on the stimulus-level ranges, "extension of stimulus levels", step size and equipment reproduces the IMPC counts **exactly**. Example: HMGU *Zbtb24*'s 7 mutants used `Extension of stimulus levels = 95.0`, a setting shared by only 16 controls (8 F + 8 M) out of HMGU's ~2,800. Harwell's `em1(IMPC)H` CRISPR lines sit in an equipment-defined group of only 34 F / 36 M. MARC's *Usp16* is the extreme end — its equipment model + software (`Cambridge Electronic Design`) is shared by **0** controls. The `silo_evidence` column names the binding field and value per line.

**Time-based control-matching (50, all TCP).** TCP has a single background (`C57BL/6NCrl`, all 588 controls) and uniform metadata, yet every control-limited TCP line was analysed against the **same fixed 50 F / 50 M cohort** (identical control means 31.2 / 34.0), corresponding to TCP's early controls (2013–mid-2014); the controls collected later (2015–2024) are not used. Background and procedure both match — only the control *timing* is the problem.

**Genetic Background control-matching (11).** The mutants' background has no or too few matched controls. RBRC's 8 lines are on `C57BL/6NJcl` (44 controls, only 6 female) while the bulk of RBRC's pool (296) is `C57BL/6NTac`; the IMPC used the full 6 F / 38 M, so this is a genuine shortage, not a withheld baseline. JAX's *Igfl3* and *Sema6a* are tagged `C57BL/6N` while every JAX control is `C57BL/6NJ` → 0 matched (a substrain-label mismatch; C57BL/6NJ is the NIH N-substrain, distinct from C57BL/6J and without the *Nnt* deletion). HMGU's *Eci2* is `C57BL/6NCrl` but HMGU's `C57BL/6NCrl` controls did not begin until Dec 2016 — *Eci2* ran May 2016, so 0 same-background controls existed contemporaneously (the 246 controls present then were `C57BL/6NTac`, excluded on background).

**On soft windowing.** For the stimulus/equipment-config centres the discrete metadata-group match is *exact*, with no temporal weighting needed — the count is set by which metadata group a mouse falls in. This is consistent with WTSI's statement that they do not soft-window ABR data; soft windowing ([Haselimashhadi et al., *Bioinformatics* 2020](https://academic.oup.com/bioinformatics/article/36/5/1492/5583690)) weights controls by temporal proximity to the mutant and would also exclude temporally distant controls, but it is not the driver of these particular ineligible cases.

**Why all 412 are effectively frozen.** Each line's silo is anchored to attributes fixed in the past — its test date (ABR_001 and TCP), a non-standard one-off stimulus/equipment configuration, or a background with no/too few matched controls. Even the still-active high-volume centres (HMGU, CCP-IMG, JAX, TCP) hold thousands of controls now, yet these historical lines still draw <60/sex, because the later controls fall outside the line's silo. Only a change to the IMPC's control-matching methodology — not the passage of time or further data collection — would move these lines above the threshold.

### Note on local replication

Replicating the rule on the local dataset with `ControlMatcher` (centre + background + pipeline + equipment + procedure) does not reproduce the IMPC counts, because the project matcher does not silo on the full ABR metadata group (stimulus settings) or on the per-sex/contemporaneous control selection the IMPC uses. The authoritative IMPC counts from `stat_processed_data.csv` (per-sex, per metadata group) should be used in the manuscript, not a local re-derivation.

## ABR_001 deliverable for Sherri

`data/processed/abr_001_mutant_control_counts.csv`: every experimental subgroup (gene × allele × zygosity × centre) tested under `procedure_stable_id: IMPC_ABR_001`, with `n_mutants` and the number of controls **matched to that knockout** on the project `ControlMatcher` criteria (centre + genetic background + pipeline + equipment manufacturer + model). Columns: `n_controls_matched` / `n_controls_matched_complete` (all procedures) and `n_controls_matched_abr001` / `..._complete` (restricted to ABR_001 controls); the matching metadata (background, equipment, pipeline) is included per row.

- **892 unique genes**, 961 subgroups, 4,424 mutant mice. Group metadata is consistent across the mutants within every subgroup.
- ABR_001 mutants occur only at WTSI (805 genes), MRC Harwell (81), HMGU (14).
- Equipment/background matching naturally restricts to the ABR_001-era control pool, so `n_controls_matched` and `n_controls_matched_abr001` are nearly identical. Per-centre matched pools (complete): MRC Harwell 858, HMGU 755, WTSI mostly 904 — **but** 8 WTSI subgroups (7 genes: Acsl4, Crlf3, Fundc1, Inpp1, Pld5, Slc25a21, Spns2) match only **54** controls, a narrower background/equipment subset.
- Caveat: these matched counts use the project matcher. The IMPC's own pipeline matches more granularly (it reported 11–43 matched controls for the same WTSI lines), which is why its ≥60 rule blocks them. Both agree the low-control ABR_001 lines are at WTSI; Sherri's "should only come up with Harwell & WTSI" hypothesis still does not hold — Harwell's matched pools are all ≥60.
